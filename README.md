# Counter

iOS projects for the Yandex Practicum course.

## Projects

### ImageFeed (Sprints 8–9)

Photo feed app built with UIKit.

**Features:**
- Launch screen with the Practicum logo
- Image feed with `UITableView`, likes, and dynamic cell heights
- Full-screen image viewer with zoom and share
- User profile screen
- Tab bar navigation between feed and profile

**Requirements:** iOS 17.0+, iPhone, portrait orientation only.

**Run:**
```bash
open ImageFeed.xcodeproj
```
Select the **ImageFeed** scheme and run on an iPhone simulator.

### MovieQuiz (Sprints 4–7)

Movie quiz app with network loading and MVP architecture.

**Run:**
```bash
open MovieQuiz.xcodeproj
```
